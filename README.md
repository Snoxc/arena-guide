# Alexandr Guide v5.10.15 — Snow Header Clean

Полный проект на базе версии v5.10.14 Snow Only. Содержит все исходные видеофайлы, фотографии и страницы.

## Установка
Распакуйте ZIP и загрузите содержимое корневой папки на хостинг (или откройте `index.html` локально). После обновления GitHub Pages обновите страницу с очисткой кеша (`Ctrl+F5`).

## Что изменилось
- Кнопка снежинки теперь первая в header.
- Удалены иконка внешней ссылки Arena.ai и лишний символ `>`.
- На мобильных устройствах поиск доступен только из нижней панели (до 900 px).
- Hover изменяет только цвет самой иконки без цветной подложки.

Кнопка снега работает как раньше: включает и выключает снег, запоминает выбор.
